# Tài liệu dự án

- `project-brief.md`: yêu cầu và phạm vi ban đầu.
- `specifications/ptyc.md`: đặc tả toán học và thiết kế kỹ thuật.
- `specifications/product-backlog.md`: backlog triển khai và kiểm chứng.
- `research/`: ghi chú nghiên cứu và workbook tổng hợp metric.

Bài báo gốc và bản text đã trích xuất được giữ riêng trong `papers/` ở thư mục gốc.
